# Photo Meta Data

Photo Meta Data is a simple tool for managing and organizing image metadata.

It allows you to:

* Remove metadata from your photos.
* Edit and update photo metadata.
* Apply the same metadata changes to multiple images at once.
* Create custom categories and metadata presets.
* Process hundreds or even thousands of images from a folder in one operation.
* Organize and number photos based on their date and metadata.
* Sort and categorize your images using your own rules.

Whether you need to clean, edit, organize, or standardize metadata across a large collection of photos, Photo Meta Data makes the process simple and fast.
